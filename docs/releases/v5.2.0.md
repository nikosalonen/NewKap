# Kap v5.2.0

Tag: `v5.2.0`

Kap v5.2.0 is the first release from the [nikosalonen/NewKap](https://github.com/nikosalonen/NewKap) fork. It runs natively on Apple Silicon without Rosetta, moves to Electron 45, removes crash reporting, and fixes screen recording permissions on current macOS.

## Requirements

- An Apple Silicon Mac (M1 or newer). There is no Intel build; Intel Macs can keep using [Kap 5.1.0](https://github.com/jacobpowaza/NewKap/releases/tag/v5.1.0).
- macOS 13 Ventura or later. Electron 45 no longer supports macOS 12.

## Install

1. Download `Kap-5.2.0-mac-arm64.dmg`, open it, and drag `Kap.app` into Applications. It replaces an older Kap there; your settings and plugins stay.
2. Open Kap. This release is signed with the fork's own certificate and is not notarized by Apple, so macOS refuses to open it the first time. Close the message, open **System Settings -> Privacy & Security**, and click **Open Anyway** next to the message about Kap.
3. Grant Screen Recording permission when macOS asks. If you used another Kap build before, macOS asks once more. Later releases from this fork are signed with the same certificate and keep the permission.

## Changes

- **Apple Silicon only.** A small Swift helper replaces four Intel-only native modules, so listing microphones, picking a window and "Open With" work without Rosetta. Packaged builds contain no Intel code.
- **Permissions.** Screen recording and microphone checks no longer depend on an Intel-only helper, which made Kap report "cannot record the screen" forever. Kap asks macOS again after an update that changes its signature, and it keeps running after opening System Settings for you; macOS offers **Quit & Reopen** when you turn access on.
- **Privacy.** Sentry crash reporting and the analytics stub are gone. Packaged 5.1.0 builds sent crash reports to the original Kap project by default.
- **Plugins.** Links from plugins open only web and email addresses.
- **Updates.** **Check for Updates...** looks at this fork's releases.
- **Security.** Each window's Content-Security-Policy applies as soon as it loads, the bundled gifsicle binary is checked against a pinned SHA-256 at build time, and `pnpm audit` reports no critical or high issues.
- **Under the hood.** Electron 45, Next.js 16, React 19, electron-builder 26, Node 24 and pnpm for development.

## Updating from 5.1.0

Kap 5.1.0 checks the upstream repository for updates, so it does not announce this release. Download it from this page.

## Known issues

- Not notarized: macOS asks you to approve each downloaded version once with **Open Anyway**.
- Recording still uses aperture's AVFoundation recorder, not ScreenCaptureKit. macOS 15 and later may ask from time to time whether Kap may keep recording the screen.
- System audio capture needs a loopback audio device, because macOS does not offer output audio as a microphone.
