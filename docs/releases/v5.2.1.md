# Kap v5.2.1

Tag: `v5.2.1`

Kap v5.2.1 fixes how Preferences shows the recordings folder, moves the web requests that plugins make off a library with a security advisory, and updates libraries inside the app.

## Requirements

- An Apple Silicon Mac (M1 or newer). There is no Intel build; Intel Macs can keep using [Kap 5.1.0](https://github.com/jacobpowaza/NewKap/releases/tag/v5.1.0).
- macOS 13 Ventura or later.

## Install

1. Download `Kap-5.2.1-mac-arm64.dmg`, open it, and drag `Kap.app` into Applications. It replaces an older Kap there; your settings and plugins stay.
2. Open Kap. This release is signed with the fork's own certificate and is not notarized by Apple, so macOS refuses to open it the first time. Close the message, open **System Settings -> Privacy & Security**, and click **Open Anyway** next to the message about Kap.
3. Coming from 5.2.0, Screen Recording and Microphone permissions carry over, because both releases use the same certificate. Coming from another Kap build, macOS asks once more.

## Updating from 5.2.0

Kap 5.2.0 checks for updates every hour and offers this release, or right away when you choose **Check for Updates…**. **Update** downloads the DMG; install it as described above.

## Changes

- **Preferences.** The recordings folder shows as `~/Movies/Kaptures` again instead of the full path.
- **Plugins.** Web requests from plugins (`context.request`) use got 11 instead of got 9, which has a security advisory ([GHSA-pfrx-2q88-qq97](https://github.com/advisories/GHSA-pfrx-2q88-qq97): a redirect could reach a local UNIX socket). Kap translates the got 9 options that published plugins pass, so they keep working. [docs/plugins.md](https://github.com/nikosalonen/NewKap/blob/main/docs/plugins.md) lists the few got 9 options it doesn't translate.
- **Under the hood.** Messages between Kap's windows use electron-better-ipc 3. A message that nothing answers now fails with an error instead of waiting forever. Several smaller libraries are updated, and the type checks are stricter. Dependabot alerts for KaTeX and minimatch are fixed; those copies were only in development tools, not in the app.

## Known issues

- Not notarized: macOS asks you to approve each downloaded version once with **Open Anyway**.
- Recording still uses aperture's AVFoundation recorder, not ScreenCaptureKit. macOS 15 and later may ask from time to time whether Kap may keep recording the screen.
- System audio capture needs a loopback audio device, because macOS does not offer output audio as a microphone.
