# Kap v5.2.3

Tag: `v5.2.3`

Kap v5.2.3 prepares the update check for future releases that need a newer macOS.

## Requirements

- An Apple Silicon Mac (M1 or newer). There is no Intel build; Intel Macs can keep using [Kap 5.1.0](https://github.com/jacobpowaza/NewKap/releases/tag/v5.1.0).
- macOS 13 Ventura or later.

## Install

1. Download `Kap-5.2.3-mac-arm64.dmg`, open it, and drag `Kap.app` into Applications. It replaces an older Kap there; your settings and plugins stay.
2. Open Kap. This release is signed with the fork's own certificate and is not notarized by Apple, so macOS refuses to open it the first time. Close the message, open **System Settings -> Privacy & Security**, and click **Open Anyway** next to the message about Kap.
3. Coming from 5.2.x, Screen Recording and Microphone permissions carry over, because these releases use the same certificate. Coming from another Kap build, macOS asks once more.

## Updating from 5.2.x

Kap checks for updates every hour and offers this release, or right away when you choose **Check for Updates…**. **Update** downloads the DMG; install it as described above.

## Changes

- **Update check.** A future release may need a newer macOS than this one. On a Mac that can't run it, Kap no longer offers that release, and **Check for Updates…** says which macOS it needs. Kap 5.2.3 keeps working on that Mac.
- **From 5.2.2.** Hiding a Kap window no longer shows the error "TypeError: Cannot read properties of undefined (reading 'values')". If you skipped 5.2.2, you get this fix now.

## Known issues

- Not notarized: macOS asks you to approve each downloaded version once with **Open Anyway**.
- Recording still uses aperture's AVFoundation recorder, not ScreenCaptureKit. macOS 15 and later may ask from time to time whether Kap may keep recording the screen.
- System audio capture needs a loopback audio device, because macOS does not offer output audio as a microphone.
